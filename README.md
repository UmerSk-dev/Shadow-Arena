
# ⚔️ Shadow Arena

A 2.5D fighting game built using **HTML, CSS, JavaScript and Three.js**, featuring 3D fighters, weapons, combat mechanics and a dark fantasy arena.

## 🎮 About the Project

Shadow Arena is a browser-based 1v1 fighting game where players battle an AI-controlled opponent using different attacks and defensive moves.

The game combines 3D character models and environments with 2D-style fighting mechanics to create a simple fighting game experience.

This project is being developed as a hands-on JavaScript learning project, focusing on game logic, keyboard events, object manipulation and Three.js.

## ✨ Features

- 3D player and enemy fighters
- 3D weapons such as swords and katanas
- Dark fantasy fighting arena
- Player movement and jumping
- Punch and kick attacks
- Sword attack mechanics
- Blocking and damage system
- AI-controlled opponent
- Player and enemy health bars
- Win and Lose conditions
- Restart functionality

## 🛠️ Technologies Used

| Technology | Purpose |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/ShadowArena.git
```

### 2. Open the Project

```bash
cd ShadowArena
```

Open the folder in Visual Studio Code.

### 3. Run the Game

- Install the Live Server extension in VS Code.
- Open `index.html`.
- Right-click and select **Open with Live Server**.
- The game will open in your browser.
